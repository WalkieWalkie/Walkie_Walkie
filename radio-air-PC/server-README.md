# Сервер эфира «Радио»

Свой эфир для программ «Радио» и «Рация» и для приёмника в браузере. Сервер пересылает живые
станции тем, кто настроен рядом с их частотой, и ничего не записывает.

Внутри: `server.py` (сам сервер, только стандартная библиотека Python), `autostart.py` (запуск в
фоне, служба, HTTPS) и страницы приёмника и рации для гостей из браузера.

## Что нужно

- Windows 10, 11 или Windows Server.
- [Python](https://www.python.org/downloads/) 3.11 или новее — с python.org, не из Microsoft Store.
  При установке отметьте **Add python.exe to PATH**.
- Белый IP. У VPS он есть всегда; дома — уточните у провайдера.

## Установка на VPS

1. Подключитесь к серверу по RDP («Подключение к удалённому рабочему столу», адрес и пароль —
   из письма провайдера).
2. Установите Python (см. выше).
3. Скопируйте архив на сервер — обычное «Копировать» у себя и «Вставить» в окне RDP — и
   распакуйте, например в `C:\Radio`.
4. Откройте PowerShell **от имени администратора** (правый щелчок по «Пуску» → «Терминал
   (администратор)») и выполните:

   ```
   cd C:\Radio
   python autostart.py service on
   ```

   Сервер запустится и дальше будет стартовать вместе с Windows — даже после перезагрузки из-за
   обновлений, когда в систему никто не входит. Если он упадёт, служба поднимет его снова.
   Порт 8765 откроется в брандмауэре Windows.
5. Если у провайдера в панели управления есть свой брандмауэр («firewall», «группы безопасности»),
   откройте там входящий **TCP 8765**.
6. Проверьте со своего компьютера: откройте в браузере `http://IP-сервера:8765` — должен появиться
   приёмник.

Друзья подключаются по адресу `IP-сервера:8765`: в «Рации» — MENU → 12 SERVER, в «Радио» —
панель «Сервер».

## Управление

```
python autostart.py status    что работает, открыт ли порт, есть ли сертификат
python autostart.py restart   перезапустить, например после обновления файлов
python autostart.py stop      остановить (до следующей перезагрузки или start)
python autostart.py start     запустить снова
python autostart.py service off   убрать службу и правило брандмауэра
```

Команды управления службой выполняются в PowerShell от имени администратора.
Журнал сервера — `server.log` рядом со скриптами.

**Обновление:** замените файлы новыми из архива (журнал и `Caddyfile` можно не трогать) и
выполните `python autostart.py restart`.

## HTTPS — чтобы в браузере работал микрофон

Браузер пускает к микрофону только по HTTPS. Программам «Радио» и «Рация» HTTPS не нужен.

1. Заведите домен (подойдёт и бесплатный, например на DuckDNS) и направьте его на IP сервера.
2. Скачайте Caddy для Windows (amd64) с [caddyserver.com/download](https://caddyserver.com/download),
   переименуйте в `caddy.exe` и положите в папку `tools`.
3. В PowerShell от имени администратора:

   ```
   python autostart.py https radio.example.ru
   ```

   Caddy сам получит бесплатный сертификат Let's Encrypt и будет его продлевать. Порты 80 и 443
   откроются в брандмауэре Windows; в панели провайдера, если там свой брандмауэр, откройте их тоже.

Выключить: `python autostart.py https off`.

## На домашнем компьютере

Если в систему вы и так входите каждый день, служба не обязательна:

```
python autostart.py on
```

Сервер будет запускаться при входе в Windows, права администратора не нужны. В роутере нужно
пробросить TCP 8765 на этот компьютер (или открыть свой сервер из программы «Радио» — она сделает
это сама через UPnP).

## Переезд с другого компьютера

На старом компьютере выполните `python autostart.py off` (или `service off`), а в программе
«Радио» нажмите «Закрыть свой сервер» — порт в роутере закроется. Друзьям сообщите новый адрес.

## Что стоит знать

- Сервер **без пароля**: подключиться, слушать открытые каналы и выйти в эфир может любой, кто знает
  адрес. Позывные не проверяются. Для приватных разговоров — шифрование (ключ канала / SCR).
- Шифрованный звук сервер прочитать не может, но видит, кто, когда и на какой частоте говорит.
- Сервер ничего не записывает на диск, кроме журнала запуска и ошибок.
- Трафик: около 64 кбит/с на каждого слушателя каждой станции (голос сжат в IMA ADPCM). Десять
  слушателей одной станции — примерно 0,65 Мбит/с исходящего. Радиостанция для Android шлёт звук
  несжатым — от неё около 256 кбит/с на слушателя.
- Если на VPS открыт RDP, поставьте длинный пароль: такие серверы постоянно пытаются подобрать.
