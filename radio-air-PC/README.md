# Радио — эмулятор эфира

Радиоэфир в браузере: шкала, помехи, станции, шифрованный канал, азбука Морзе
и живой эфир — свои станции, которые слышат все, кто настроится рядом.

## Запуск

Нужен только Python 3.9+, ничего устанавливать не надо:

```bash
python server.py
```

Откройте http://localhost:8765 и нажмите **ВКЛ**.

Чтобы слушать с телефона или другого компьютера в той же Wi-Fi сети:

```bash
python server.py --host 0.0.0.0
```

Сервер напечатает адрес для других устройств. Windows может спросить, пускать ли Python в сеть.
С других устройств можно только слушать: браузеры дают микрофон лишь на localhost или по HTTPS.

## Автозапуск

Чтобы сервер сам стартовал при входе в Windows и работал в фоне без окна:

```bash
python autostart.py on
```

| Команда | Что делает |
|---|---|
| `python autostart.py on` | Включает автозапуск и сразу запускает сервер |
| `python autostart.py off` | Выключает автозапуск и останавливает сервер |
| `python autostart.py status` | Показывает, включён ли автозапуск и работает ли сервер |
| `python autostart.py restart` | Перезапускает сервер и HTTPS — нужно после обновления `server.py` |
| `python autostart.py start` / `stop` | Запускает или останавливает сервер и HTTPS, не трогая автозапуск |
| `python autostart.py https ДОМЕН` / `https off` | Включает или выключает HTTPS (см. ниже) |

Фоновый сервер открыт для сети (`--host 0.0.0.0`) и пишет журнал в `server.log`. Права администратора
не нужны. Отключить автозапуск можно и в Диспетчере задач → «Автозагрузка приложений».
Если переустановите Python в другую папку — выполните `python autostart.py on` ещё раз.

Сервер занимает порт монопольно: если запустить второй, пока работает фоновый, он откажется
и скажет почему.

## Доступ из интернета (белый IP)

Минимум, чтобы друзья могли слушать ваш эфир:

1. Убедитесь, что IP белый: адрес WAN в роутере совпадает с тем, что показывает 2ip.ru.
2. В роутере пробросьте TCP-порт 8765 на домашний адрес компьютера (его печатает сервер
   в `server.log`, строка «В локальной сети»). Этот адрес лучше закрепить за компьютером в DHCP роутера.
3. Включите автозапуск (см. выше) и дайте друзьям ссылку `http://ВАШ_IP:8765`.

Без HTTPS гости могут только слушать открытые станции: отвечать в эфир и расшифровывать каналы
браузер разрешит им только по HTTPS — см. следующий раздел.

## HTTPS

С HTTPS у гостей работает всё: микрофон, рация, шифрованные каналы. Сертификат бесплатный
(Let's Encrypt), получает и продлевает его [Caddy](https://caddyserver.com) — `tools/caddy.exe`.

1. **Домен.** Сертификат выдают на имя, не на IP. Варианты:
   - поддомен своего домена: в DNS на Webnames добавьте A-запись, например `radio` → ваш белый IP;
   - бесплатный [DuckDNS](https://www.duckdns.org): заведите имя и впишите белый IP вручную
     (с включённым VPN сайт может подставить адрес VPN, а не ваш).
2. **Роутер.** Пробросьте TCP-порты **80 и 443** на компьютер (`192.168.1.74`). Порт 8765 наружу
   после этого не нужен.
3. **Включите HTTPS:**
   ```bash
   python autostart.py https radio.вашдомен.ru
   ```
   Windows спросит, пускать ли Caddy в сеть, — разрешите.
4. **Проверьте** через минуту:
   ```bash
   python autostart.py status
   ```
   Должно быть «сертификат Let's Encrypt, действует до …». Если нет — смотрите `caddy.log`.
   Частые причины: не проброшены порты, домен ещё не указывает на ваш IP, мешает TUN-режим VPN.

Ссылка для друзей — `https://radio.вашдомен.ru`. Caddy запускается вместе с сервером при входе
в Windows. Выключить: `python autostart.py https off`.

Если домен не открывается изнутри домашней сети (не все роутеры это умеют), на своём компьютере
пользуйтесь `http://localhost:8765` — там микрофон работает и без HTTPS.

Если на компьютере включён VPN или прокси в режиме TUN (например, FlClashX), он может перехватывать
ответы на входящие подключения — тогда друзья не достучатся. Проверьте без TUN-режима.

## Приложение для Windows

Установщик: `Radio-Setup-0.X.Y.exe` в [релизах](https://github.com/WalkieWalkie/Walkie_Walkie/releases)
(релиз `v0.X.Y`, «Latest»); собранный у себя — в `desktop/dist/`. Ставится в профиль пользователя
без прав администратора. Установщик не подписан, поэтому Windows может показать «Windows защитил
ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

Дальше приложение обновляется само: проверяет релизы при запуске и раз в час и ставит новую версию,
когда станция не в эфире. Вручную — вкладка «Сервер» → «Обновления» → «Проверить сейчас». Как
выпускать — в [RELEASING.md](../RELEASING.md), шаг 3Б.

Чем приложение удобнее сайта:
- **Микрофон работает без HTTPS и домена** — достаточно адреса сервера вида `89.179.1.2:8765`.
- **Панель «Сервер»:** подключение по адресу, список недавних серверов.
- **«Открыть свой сервер»** — сервер встроен в приложение. Приложение само просит роутер открыть
  порт (UPnP) и показывает адрес для друзей. Если на компьютере уже работает `server.py`,
  приложение подключается к нему и открывает порт для него. Такой порт остаётся открытым и после
  выхода из приложения — сервер ведь продолжает работать; закрыть его можно кнопкой
  «Закрыть свой сервер».
- **F8** — рация из любого окна, даже когда приложение свёрнуто: «держу — говорю» или «нажал /
  нажал» (клавиша и режим настраиваются в полоске рации). Пока идёт передача, в заголовке окна
  горит «● Передача».

Приложение, браузер и `server.py` говорят на одном протоколе: гости могут приходить откуда угодно.
Встроенный сервер работает, пока открыто приложение; для круглосуточного эфира удобнее
`server.py` с автозапуском, а приложение — чтобы говорить.

Сборка (нужен Node.js):

```bash
cd desktop
npm install
npm start
```

`npm start` запускает приложение из исходников, `npm run dist` собирает установщик в `desktop/dist`.
Значок рисует `python build/make_icon.py`.

## Рация-виджет

Маленькая рация на рабочий стол по мотивам Quansheng UV-K5. В приложении — кнопка **РАЦИЯ**
в большом окне; обратно — кнопка ⤢ на рации. Приложение открывается в том виде, в каком его
закрыли. Рацию можно перетаскивать за корпус, место запоминается. Кнопка 📌 (или меню 15 TOP) —
поверх всех окон. В браузере рация открывается по адресу `/widget.html`.

**Частоты.** Переговоры идут отдельно от FM-станций. Большое окно работает только в FM и рации
не слышит: чтобы поговорить с другом, у которого рация, переключитесь в рацию и встаньте на тот же
канал. Рация в FM (F+0) может слушать станции, но передаёт всегда на своём канале.

- **MR** — каналы: PMR446 1–16 (446.00625–446.19375 МГц) или LPD 1–69 (433.075–434.775 МГц);
- **VFO** — любая частота 400–470 МГц (цифрами: `446006` → 446.00625 с учётом шага);
- **FM-радио** 88–108 МГц со встроенными станциями — **F+0**.

Каналов два — **A** и **B**, рабочий отмечен ▶.

**Кнопки**

| Кнопка | Что делает |
|---|---|
| Ручка | Щелчок — включить/выключить, колесо или протяжка вверх-вниз — громкость |
| PTT (сбоку) | Держите и говорите. То же — пробел. **F8** — вкл/выкл передачу из любого окна |
| MON (сбоку) | Monitor: открыть шумоподавитель и послушать эфир |
| ☼ (сбоку) | Фонарик |
| ▲ ▼ | Канал или частота (в меню — пункт или значение) |
| 0–9 | Номер канала (MR) или частота (VFO, FM) |
| MENU / EXIT | Меню и подтверждение / назад, отмена, выход из FM |
| Держите ✱ | Сканирование: останавливается на передаче и ждёт 3 с после неё. ▲▼ меняют направление |
| F, затем цифра | Функции: **1** PMR↔LPD, **2** канал A/B, **3** VFO/MR, **7** VOX, **0** FM-радио |
| Держите F | Блокировка кнопок (PTT и боковые работают) |

Светодиод: красный — передача, зелёный — приём. На экране: уровень сигнала, F, DW, VOX, S (шифр),
MON, замок, NET (связь с сервером).

**Меню** (MENU, затем ▲▼ или номер пункта цифрами; MENU — изменить, MENU — сохранить, EXIT — отмена)

| № | Пункт | Значения |
|---|---|---|
| 1 | SQL — шумоподавитель | 0–9 (0 — выключен) |
| 2 | STEP — шаг частоты в VFO | 2.5 / 5 / 6.25 / 10 / 12.5 / 25 кГц |
| 3 | SCR — скремблер: ключ и передачи, и приёма | OFF, ключи из связки, «новый» |
| 4 | VOX — передача голосом | OFF, 1–10 (чувствительность) |
| 5 | MIC — чувствительность микрофона | 0–4 |
| 6 | TOT — предел длины передачи | 1–10 мин |
| 7 | ROGER — сигнал в конце передачи | ON / OFF |
| 8 | DW — двойное прослушивание A+B | ON / OFF |
| 9 | BEEP — звук кнопок | ON / OFF |
| 10 | ABR — подсветка экрана | всегда, 5–30 с |
| 11 | NAME — позывной | текст с клавиатуры |
| 12 | SERVER — сервер | недавние адреса или новый |
| 13 | AUTO — подключаться при запуске | ON / OFF |
| 14 | HOST — свой сервер | ON / OFF (показывает адрес для друзей) |
| 15 | TOP — поверх всех окон | ON / OFF |

Пункты 12–15 есть только в приложении. Текст (позывной, адрес, ключ) набирается на клавиатуре
компьютера, Enter — готово, Esc — отмена.

**Двойное прослушивание.** Слышны оба канала. Если ответили на втором, у него появляется «>», и
5 секунд после приёма PTT отвечает туда же, как у UV-K5.

**Шифрование (SCR)** работает как скремблер настоящей рации: один ключ и на передачу, и на приём.
Шифрованный канал слышен, только если в SCR выбран тот же ключ; при OFF или другом ключе — цифровой
треск, даже если нужный ключ лежит в связке большого окна. Связка — просто список, из которого ключ
удобно выбрать в меню. Сервер и автоподключение у рации и большого окна общие.

## Полоска поверх игр и видео

Рацию можно свернуть ещё сильнее — в полоску, как у программ записи экрана: кнопка ▭ над рацией
(обратно — ⤢ на полоске). Это та же рация: связь не рвётся, каналы и настройки те же.

```
● ГОСТЬ │ A▶ PMR 1 │ B 433.075 │ ▮▮▮▯▯ │ F8 │ ⚙ ⤢
```

- **Лампа:** серая — тихо, зелёная с позывным — кто-то говорит, красная с таймером — говорите вы,
  мигающая оранжевая — нет связи с сервером, синяя — сканирование.
- **Каналы A и B:** щелчок — сделать рабочим, колесо мыши — сменить канал.
- **Микрофон:** уровень голоса; отметка — порог VOX.
- Полоска **не забирает фокус** (щелчок по ней не сворачивает игру) и держится **поверх всех окон**.
  По умолчанию стоит сверху по центру экрана, её можно перетащить — место запоминается.

**⚙ Настройки:**
- **Горячие клавиши** — щёлкните по полю и нажмите клавишу (или боковую кнопку мыши), Esc — отмена.
  Действия: рация, канал A/B, канал ▲▼, без звука, рация ⇄ полоска, спрятать/показать.
  По умолчанию: рация — **F8**, спрятать/показать — **Ctrl+Shift+F8**.
- **Рация на клавише:** «Держу — говорю» (как в Discord) или «Нажал / нажал».
- **Прозрачность**, **громкость**, **проверка микрофона**.
- **Мышь насквозь:** полоска не перехватывает щелчки, а с зажатым **Alt** её можно двигать и нажимать.

Горячие клавиши работают в любом окне, в том числе в играх. Для этого приложение слушает клавиатуру
и мышь через модуль [uiohook-napi](https://github.com/SnosMe/uiohook-napi) — как Discord для
«push-to-talk»: нажатия только сравниваются с назначенными клавишами, никуда не записываются и не
отправляются, а сама клавиша доходит и до игры. Если модуль не загрузится, клавиши работают только
как «нажал / нажал».

В играх полоска видна в режиме **«Оконный без рамки»**. В эксклюзивном полноэкранном режиме её не
видно (в игру приложение не встраивается — так не забанит античит), но горячие клавиши и звуки
работают.

## Сервер на VPS или другом компьютере

`python pack_server.py` собирает `release/radio-server-0.X.Y.zip` (версия — как у «Радио»):
сервер, автозапуск, страницы приёмника и рации и инструкцию (`server-README.md`). Как и архив
рации, перед упаковкой он проверяется на секреты и личные данные.

На VPS с Windows, куда никто не входит, сервер ставится **службой** (PowerShell от имени
администратора):

```bash
python autostart.py service on
```

Задача планировщика от имени SYSTEM запускает сервер при старте Windows, ещё до входа в систему,
поднимает его, если он упал, а порт 8765 (и 80/443 при HTTPS) открывается в брандмауэре.
`service off` убирает и то и другое. `status`, `restart`, `stop`, `start` работают и в этом режиме.

## Отдельная программа «Рация»

Рацию можно поставить и без большого приёмника — отдельной программой со своим значком. Это та же
оболочка (`desktop/main.js`) в режиме «только рация»: большого окна и кнопки ⤢ нет, свой сервер
отдаёт гостям из браузера рацию. Настройки у «Рации» и «Радио» свои, работать они могут и вместе
(только не назначайте обоим одну клавишу рации — сработают оба).

```bash
python pack_walkie.py          # исходники рации и архив для друзей
python pack_walkie.py --build  # то же и установщик
```

Всё складывается в `release/`:
- `radio-walkie-0.X.Y-src.zip` — исходники только рации (файлы из списка в скрипте, свой README
  и package.json);
- `Walkie-Setup-0.X.Y-walkie.0.exe` — установщик, собранный из этих же исходников (с `--build`);
- `radio-walkie/` — распакованная копия для сборки.

Версия «Рации» — версия «Радио» с суффиксом `-walkie.0`. Готовая «Рация» выходит отдельным
pre-release `v0.X.Y-walkie.0` в [релизах](https://github.com/WalkieWalkie/Walkie_Walkie/releases)
и обновляется своим каналом (`walkie.yml`), независимо от «Радио» (`latest.yml`).

Перед упаковкой скрипт проверяет файлы на секреты (ключи, токены, пароли, `.env`) и личные данные
(почта, адреса домашней сети, имя пользователя и компьютера); если что-то нашлось, архив не
создаётся. В архив попадают только файлы из списка в скрипте. Значок рации рисует
`python desktop/build/make_walkie_icon.py`, README для друзей — `desktop/walkie-README.md`.

## Живой эфир

Панель **«Мой эфир»**: позывной, частота, ключ канала, источник (микрофон и/или плейлист), режим.

**Плейлист.** Добавьте треки кнопкой «Треки…» (можно выбрать сразу несколько) или перетащите файлы
в плейлист. Пока вы в эфире, они играют один за другим: **по кругу** или **случайно** (в случайном
режиме за круг звучат все треки, и один и тот же не повторяется подряд). «Следующий» переключает трек,
клик по треку включает его сразу, а вне эфира выбирает, с какого начать. Файлы читаются потоково,
поэтому длинный плейлист не занимает много памяти. После перезагрузки страницы плейлист нужно собрать
заново — браузер не даёт сайтам запоминать файлы с диска.

- **Постоянный** — передача идёт всё время, как у радиостанции.
- **Рация** — передача только пока держите кнопку или пробел. Отпустили — у слушателей снова шум.

**«Слышать себя»** (галочка у источника, включена по умолчанию): сервер возвращает вам ваш же эфир,
и в приёмнике он звучит так же, как у слушателей — с задержкой, помехами и расстройкой. Свой
шифрованный эфир расшифровывается ключом канала сам, добавлять его в связку не нужно. Слушайте в
наушниках, иначе микрофон услышит динамики и пойдёт эхо. Рация-виджет себя не слышит, как настоящая.

На передаче звук проходит эфирную обработку (компрессор), поэтому голос и музыка звучат примерно
одинаково громко.

Микрофон во встроенном браузере Claude заблокирован — для голоса откройте страницу в обычном Chrome.

## Шифрование

Если в «Моём эфире» задан **ключ канала**, звук шифруется прямо на устройстве (AES-GCM, ключ выводится
из фразы через PBKDF2). Сервер пересылает байты, которые не может прочитать; сама фраза никуда не уходит.

Слушатель добавляет ту же фразу в **«Ключи шифрования»** — и слышит голос. Без ключа (или с неверным)
слышны сами зашифрованные данные: они модулируются четырьмя тонами (4FSK), как в цифровых рациях.
Регистр и пробелы по краям не важны.

Что стоит знать:
- Стойкость зависит от фразы. Короткий ключ вроде `4271` можно подобрать перебором, если записать
  шифрованный эфир. Берите фразу из нескольких слов.
- В открытом виде видны позывной, частота, время передачи и номер ключа (по нему видно, какие передачи
  идут одним ключом, но не сам ключ).
- Шифрование работает только на localhost или по HTTPS: на телефоне по локальной сети шифрованные
  каналы пока слышны только как цифровой треск.

## Шумоподавитель

Кнопка **ШП** рядом с поиском: пока нет сильного сигнала, приёмник молчит. Началась передача —
звук открывается, закончилась — короткое «кх-х» и снова тишина. Удобно для режима рации.

## Что есть в эфире

- **Шум и настройка.** Чем точнее настройка, тем громче и чище станция и тем тише шум. При неточной
  настройке звук глухой и дрожит, у края станции свистит.
- **Встроенные станции:** музыкальная, телеграфный маяк, «жужжалка», шифрованный канал, слабая дальняя
  станция. Пока они синтезируются в каждом браузере отдельно — у разных людей звучат по-разному.
- **RDS.** Название станции появляется на дисплее по буквам и только при хорошем приёме.
- **Декодер Морзе.** Разбирает телеграф на слух — по тому звуку, что выходит из приёмника, вместе
  с помехами. Ищет ровный тон, сам подстраивается под скорость передающего (примерно 10–30 WPM) и
  одинаково работает на маяке и на любой живой станции, которая передаёт Морзе тоном. Первые знаки
  уходят на то, чтобы поймать ноту и скорость. На музыке, голосе и цифровом треске молчит: телеграф
  узнаёт по тому, что все посылки звучат на одной ноте, а в паузах тихо.
- **Ключи шифрования.**
- **Журнал эфира.** Станция попадает в журнал, если удержать её на шкале пару секунд. Любительские
  станции записываются с позывным, частотой и временем, когда их слышали; если станция сейчас
  в эфире — рядом горит отметка, у шифрованных — «ШИФР». Хранится до 50 любительских станций,
  лишние можно убрать крестиком. На шкале найденные станции отмечены треугольниками
  (любительские — красноватыми).
- Журнал, ключи, частота, громкость и настройки эфира сохраняются в браузере.

## Устройство

| Файл | Что внутри |
|---|---|
| `server.py` | Отдаёт страницу и ретранслирует живые станции по WebSocket. Ничего не записывает |
| `autostart.py` | Автозапуск сервера вместе с Windows и HTTPS через Caddy |
| `tools/caddy.exe` | Caddy 2.11.4 — HTTPS и сертификаты |
| `desktop/main.js` | Приложение: окно, свой сервер, UPnP, горячая клавиша рации |
| `desktop/air-server.js` | Сервер эфира на Node — то же, что `server.py`, внутри приложения |
| `desktop/upnp.js` | UPnP: открыть порт в роутере и узнать внешний IP |
| `desktop/hotkeys.js` | Горячие клавиши из любого окна: «держу — говорю» и «нажал / нажал» |
| `pack_walkie.py` | Сборка отдельной «Рации»: исходники, проверка на секреты, архив, установщик |
| `pack_server.py`, `server-README.md` | Архив «Сервер эфира» для VPS или другого компьютера |
| `js/engine.js` | Движок приёмника: смешивает станции и шум в зависимости от частоты |
| `js/stations.js` | Встроенные станции |
| `js/live.js` | Живые станции (приём) и передатчик (микрофон/трек → сервер) |
| `js/crypto.js` | Шифрование эфира: ключи, упаковка и распаковка пакетов |
| `js/codec.js` | Сжатие голоса IMA ADPCM: 16 бит → 4 бита на сэмпл, в 4 раза меньше данных |
| `js/playlist.js` | Плейлист передатчика: порядок, случайный режим |
| `widget.html`, `js/widget.js`, `css/widget.css` | Рация-виджет: каналы, меню, F-функции, VOX, ROGER, DW, сканирование |
| `js/link.js` | Связь с сервером |
| `js/morse-decoder.js` | Декодер Морзе на слух: ищет тон, меряет посылки и паузы |
| `js/worklets/capture.js` | Захват звука: 16 кГц, пакеты по 40 мс |
| `js/audio-kit.js` | Шумы, фильтры, простые синтезаторы |
| `js/app.js` | Интерфейс |

Звук в живом эфире: 16 кГц, моно, пакеты по 40 мс, сжатые в IMA ADPCM (4 бита на сэмпл) — около
64 кбит/с на станцию. Сервер шлёт звук станции только тем приёмникам, что настроены рядом с ней
(±0,5 МГц).

Для отладки из консоли браузера: `radio.engine`, `radio.link`, `radio.broadcaster`, `radio.morse`.
