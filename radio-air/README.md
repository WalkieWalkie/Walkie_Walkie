# Радиостанция для Android

Своя FM-станция в эфире «Радио»: телефон крутит музыку из выбранной папки на частоте 87.5–108 МГц,
а рации (режим FM-радио, **F + 0**) и ПК-приёмник «Радио» ловят её, как обычную станцию. Можно
говорить поверх музыки — как ведущий.

Станция подключается к тому же **серверу эфира**, что и рации (например, к ПК-рации друга с
включённым **14 HOST**), и говорит на том же протоколе — для сервера это обычный клиент.

## Как выйти в эфир

1. Поставьте `Station-1.0.N.apk` из [релизов](https://github.com/WalkieWalkie/Walkie_Walkie/releases).
2. **Сервер** — адрес, как в рации (`89.179.146.82:8765`, `192.168.1.10:8765`, `radio.example.ru`),
   **Подключиться**. Горит «на связи» — связь есть.
3. **Плейлист → Выбрать папку** — папка с музыкой на телефоне (вложенные папки тоже читаются).
   Форматы: MP3, M4A/AAC, FLAC, OGG/Opus, WAV — всё, что умеет телефон.
4. Частота — тяните шкалу или **−/+ 0.1**. **Позывной** — как станцию видят слушатели.
5. **Выйти в эфир.** Пока станция в эфире, в шторке висит уведомление; можно свернуть приложение и
   выключить экран — эфир продолжается.

**Как слушать:** на рации **F, 0** (FM-радио) → наберите частоту цифрами (`1000` = 100.0 МГц) или
листайте ▲▼. На ПК — приёмник «Радио» на той же частоте.

## Что умеет

| | |
|---|---|
| **Плейлист** | «По кругу» (по алфавиту) или «Случайно» (без повторов, пока не сыграют все); «Следующий ▶▶»; нажмите на трек — сыграет сразу |
| **Голос поверх музыки** | Держите кнопку 🎙 — музыка плавно приглушается, в эфир идёт голос |
| **RDS** | «Трек в RDS» — слушатели видят на экране «ПОЗЫВНОЙ · Исполнитель - Трек» (до 24 знаков) |
| **Ключ канала** | Шифрует эфир (AES-GCM) — слышно только с тем же ключом в SCR рации; без ключа — цифровой треск |
| **Слышать себя** | То, что уходит в эфир, — в наушники |
| **Громкость музыки** | Уровень музыки в эфире |
| **Слушатели** | Сколько человек настроено на частоту станции |
| **Внешний вид 🎨** | Кнопка в шапке: 9 готовых тем, дисплей (классика, OLED, ЭЛТ, стекло, ЖК), узоры, подсветка цифр, фоны дисплея и приложения — готовые или своя картинка из галереи, цвета, шрифты (в т.ч. 7-сегментный), «Сбросить» |
| **«Что нового»** | После обновления — плашка со списком изменений (из описания релиза) |
| **Уведомление** | «В эфире · 100.0 МГц»: трек, слушатели; кнопки «Следующий» и «Закончить эфир» |

**Мобильный интернет:** к серверу эфира сейчас подключается только через **VPN с иностранным
сервером**; на Wi-Fi — без него.

## Устройство

Звук делает приложение, без браузера, — поэтому эфир не глохнет в фоне:

| Файл | Что это |
|---|---|
| `Station.java` | Станция: плейлист, эфир, микширование музыки и голоса, темп 40 мс, шифрование |
| `TrackDecoder.java` | Трек → звук эфира: MediaCodec, моно, 16 кГц, кадры по 640 сэмплов |
| `Resampler.java` | Понижение частоты с фильтром 7 кГц (без свиста от наложения частот) |
| `AirPacket.java` | Пакеты звука и ключ канала — байт в байт как `radio-walkie/web/js/crypto.js` |
| `AirLink.java` | WebSocket к серверу эфира (OkHttp), переподключение, `onair` / `offair` / `listeners` |
| `Playlist.java` | Музыка из папки (Storage Access Framework), порядок, «Случайно» |
| `StationService.java` | Эфир в фоне: уведомление, WakeLock, WifiLock |
| `MainActivity.java` | Экран (WebView со страницей `assets/ui`) и мост к станции |
| `assets/ui/` | Экран в стиле ПК-программы «Радио»; `look.js` / `look.css` — внешний вид 🎨 |

Звук в эфире: PCM 16 бит, 16 кГц, моно, пакеты по 40 мс — около 256 кбит/с. Станция шлёт его
несжатым (пакеты типов 0 и 1); рации и ПК-программы сжимают голос в IMA ADPCM (типы 4 и 5,
~64 кбит/с). Приёмники понимают оба формата.

## Сборка

```bash
./gradlew assembleRelease
```

CI (workflow «Station APK») собирает APK при каждом изменении `radio-air/`. Подписывается тем же
ключом, что и рация (см. «Подпись и обновления Android» в [README](../README.md)): с секретами — в CI,
без них — неподписанный APK попадает в ветку `apk-unsigned-station` и подписывается
`android/tools/sign_v2.py`.

Выпуск обновления — кнопкой Actions → «Выпустить релиз» → `station`, см. [RELEASING.md](../RELEASING.md).
