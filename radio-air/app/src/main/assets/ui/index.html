    Приложение

    Останавливает эфир и выгружает станцию из памяти. Обычный выход кнопкой «Назад» оставляет её работать в фоне (эфир идёт, но занята память).

    Слушать станцию: рация → F, 0 (FM-радио) → наберите частоту цифрами, например 1000 = 100.0 МГц. Или ПК-приёмник «Радио» на той же частоте.
