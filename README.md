# Walkie-Walkie — Рация

Рация для компьютера и телефона по мотивам Quansheng UV-K5. Каналы PMR446 и LPD, любая частота
400–470 МГц, FM-радио, VOX, ROGER, двойное прослушивание, шифрование, компактная полоска поверх игр
на ПК и кнопка PTT поверх приложений на телефоне.

Связь идёт через **сервер эфира**. Его открывает сама ПК-рация (пункт меню **14 HOST**), к нему
подключаются другие рации — на ПК и на телефоне. Все говорят на одном протоколе и слышат друг друга.

| | Где взять | Что умеет |
|---|---|---|
| **ПК (Windows)** | `radio-walkie/` → `npm run dist` или готовый установщик | Рация, свой сервер эфира, полоска поверх игр, горячие клавиши |
| **Android** | [Релизы](https://github.com/BuninSil/Walkie-Walkie/releases) → `Walkie-1.0.N.apk` | Та же рация, кнопка PTT поверх приложений, фоновый приём |
| **Радиостанция (Android)** | [Релизы](https://github.com/BuninSil/Walkie-Walkie/releases) → `Station-1.0.N.apk` | Своя FM-станция: музыка из папки и голос в эфир на 87.5–108 МГц — [подробно](radio-air/README.md) |

**Авторы:** [BuninSil](https://github.com/BuninSil) и Valex.

## Быстрый старт

1. **На ПК** запустите рацию, включите её щелчком по ручке сверху и откройте свой сервер:
   **MENU → 14 HOST → ON**. Рация покажет адрес для друзей.
2. **На телефоне** установите APK из [релизов](https://github.com/BuninSil/Walkie-Walkie/releases),
   включите рацию и введите адрес сервера: **MENU → 1 → 2 → MENU → MENU**, в окне «Адрес сервера» —
   например `192.168.1.10:8765`, **Готово**.
3. На экране загорится **NET** — связь есть. Выберите тот же канал, что у собеседников (по умолчанию
   PMR 1), и говорите, удерживая **PTT**.

Подключиться можно и к чужому серверу — например, к ПК-рации друга: вводите его адрес так же.

## Установка на Android

1. Скачайте `Walkie-1.0.N.apk` со страницы [релизов](https://github.com/BuninSil/Walkie-Walkie/releases).
2. Откройте файл. Android попросит разрешить установку из этого источника (браузера или файлового
   менеджера) — разрешите.
3. Play Protect может предложить проверить приложение, которого нет в Google Play, — нажмите
   **«Установить всё равно»**. Приложение подписано постоянным ключом разработчика, но в магазине
   его нет, поэтому такое предупреждение возможно.
4. При первой передаче Android спросит доступ к микрофону, при включении кнопки PTT поверх
   приложений — разрешение «поверх других приложений».

**Обновления** ставятся поверх: скачайте новый APK и установите — сервер, позывной, каналы и
настройки сохранятся. Версии до 1.0.11 были подписаны временными ключами: их нужно один раз удалить
перед установкой 1.0.11.

Требования: Android 8.0 и новее.

## Установка на ПК

**Готовый установщик** `Walkie-Setup-0.1.0.exe` ставится в профиль пользователя без прав
администратора. Он не подписан, поэтому Windows может показать «Windows защитил ваш компьютер» —
нажмите «Подробнее» → «Выполнить в любом случае». Установщик собирает workflow «Windows installer»
(артефакт `walkie-windows-setup`).

**Из исходников** (нужен [Node.js](https://nodejs.org) 20 или новее):

```bash
cd radio-walkie
npm install
npm start          # запустить рацию
npm run dist       # собрать установщик в radio-walkie/dist
```

## Как пользоваться рацией

Рация одинаковая на ПК и на телефоне — кнопки, меню и экран те же.

### Частоты

- **MR** — каналы: PMR446 1–16 (446.00625–446.19375 МГц) или LPD 1–69 (433.075–434.775 МГц);
- **VFO** — любая частота 400–470 МГц (цифрами: `446006` → 446.00625 с учётом шага);
- **FM-радио** 88–108 МГц — **F + 0**.

Каналов два — **A** и **B**, рабочий отмечен ▶.

### Кнопки

| Кнопка | Что делает |
|---|---|
| Ручка | Щелчок — включить/выключить; колесо или протяжка вверх-вниз — громкость |
| **PTT** (сбоку) | Держите и говорите. На ПК — также пробел и **F8** из любого окна |
| **MON** (сбоку) | Открыть шумоподавитель и послушать эфир |
| **☼** (сбоку) | Фонарик |
| **▲ ▼** | Канал или частота (в меню — пункт или значение) |
| **0–9** | Номер канала (MR) или частота (VFO, FM) |
| **MENU / EXIT** | Меню и подтверждение / назад, отмена, выход из FM |
| Держите **✱** | Сканирование: останавливается на передаче и ждёт 3 с после неё |
| **F**, затем цифра | **1** PMR↔LPD, **2** канал A/B, **3** VFO/MR, **7** VOX, **0** FM-радио |
| Держите **F** | Блокировка кнопок (PTT и боковые работают) |

Светодиод: красный — передача, зелёный — приём. На экране: уровень сигнала, F, DW, VOX, S (шифр),
MON, замок, **NET** (связь с сервером).

### Меню

**MENU**, затем **▲▼** или номер пункта цифрами; **MENU** — изменить, **MENU** — сохранить,
**EXIT** — отмена. Текст (позывной, адрес, ключ) на ПК набирается на клавиатуре, на телефоне —
в окне ввода.

| № | Пункт | Значения |
|---|---|---|
| 1 | SQL — шумоподавитель | 0–9 (0 — выключен) |
| 2 | STEP — шаг частоты в VFO | 2.5 / 5 / 6.25 / 10 / 12.5 / 25 кГц |
| 3 | SCR — шифрование (ключ и передачи, и приёма) | OFF, сохранённые ключи, «новый» |
| 4 | VOX — передача голосом | OFF, 1–10 (чувствительность) |
| 5 | MIC — чувствительность микрофона | 0–4 |
| 6 | TOT — предел длины передачи | 1–10 мин |
| 7 | ROGER — сигнал в конце передачи | ON / OFF |
| 8 | DW — двойное прослушивание A+B | ON / OFF |
| 9 | BEEP — звук кнопок | ON / OFF |
| 10 | ABR — подсветка экрана | всегда, 5–30 с |
| 11 | NAME — позывной | текст |
| 12 | SERVER — сервер эфира | недавние адреса или новый |
| 13 | AUTO — подключаться при запуске | ON / OFF |
| 14 | HOST — свой сервер | ON / OFF (только ПК) |
| 15 | TOP — поверх всех окон | ON / OFF (только ПК) |
| 16 | STAT — статистика связи внизу экрана | ON / OFF |

**Статистика связи.** Мелкая строка внизу экрана — только во время приёма или передачи и 10 секунд
после, в покое её нет. Цифры — за текущую передачу (новая начинается после 3 секунд тишины).

- Приём: `OPUS 18K · ПОТ 0% · ОБР 0 · БУФ 0.2С` — кодек и трафик, **ПОТ** — потерянные пакеты,
  **ОБР** — сколько раз звук оборвался посреди передачи, **БУФ** — сколько голоса в запасе (на столько
  он отстаёт от говорящего).
- Передача: `TX OPUS 17K · НЕ УШЛО 0%` — сколько пакетов не пролезло в сеть: если не ноль, слабый
  канал у вас, а не у слушателей.

**Двойное прослушивание.** Слышны оба канала. Если ответили на втором, у него появляется «>», и
5 секунд после приёма PTT отвечает туда же.

### ПК: полоска поверх игр

Кнопка ▭ над рацией сворачивает её в полоску поверх всех окон (обратно — ⤢). Горячие клавиши
работают в любом окне, в том числе в играх: по умолчанию рация — **F8**, спрятать/показать —
**Ctrl+Shift+F8**. Настройки полоски — ⚙: клавиши, режим «держу — говорю» / «нажал — нажал»,
прозрачность, «мышь насквозь». Подробно — в [radio-walkie/README.md](radio-walkie/README.md).

## Android: что есть только на телефоне

Внутри APK — та же рация, что на ПК, без изменений в её коде. Android-часть заменяет оболочку
программы для Windows и добавляет то, что нужно на телефоне.

### Анонимность (⚙ → «Анонимность»)

Как у настоящей рации: без учёток, без списков, кто в сети, без координат.

- **Позывной — постоянный или случайный.** Случайный меняется при каждом запуске (ТАЙФУН-24, ИРБИС-81…),
  кнопка «🎲 Другой позывной сейчас» — сразу. Вернули «Постоянный» — вернётся ваш прежний.
- **Ключ канала (SCR) через QR.** «🎲 Случайный ключ» — ключ вида `RPPZ-AU9E-U622-GN26`; «▦ Показать QR» —
  второй телефон делает «📷 Сканировать QR» (камера, без интернета). Ключ не идёт ни через интернет, ни через
  мессенджеры — только при встрече. Показывайте QR лично: кто его сфотографирует, тот слышит канал.
- **Голос в эфире.** Свой, Бас, Аноним, Выше, Робот, Армейская — голос меняется на телефоне до шифрования
  и отправки, в эфир уходит уже изменённый (ПК и другие рации ничего менять не нужно). «▶ Проверить» —
  записать 3 секунды и послушать себя.

При смене позывного или ключа рация перезапускается на секунду; во время передачи менять не даст.

### Настройки (⚙ над рацией)

| Раздел | Варианты |
|---|---|
| Корпус | Графит, Олива, Ночь, Оранж, Красный, Песок |
| Подсветка экрана | Зелёная, Янтарь, Лёд, Белая, Красная |
| Надписи F-функций | Оранж, Жёлтые, Голубые, Зелёные, Красные |
| Телефон | Кнопка PTT поверх приложений, «Не гасить экран», вибрация кнопок |

### Кнопка PTT поверх приложений

Круглая кнопка поверх любых приложений — отвечать, не открывая рацию.

- **Держите** — говорите (как PTT на рации).
- **Короткое нажатие** — открыть рацию.
- **Потащите** — переставить; место запоминается.
- Цвет кольца: серое — на связи, **зелёное** — приём, **красное** — передача, **оранжевое** — нет связи.

Включается в настройках или кнопкой в уведомлении. Кнопка видна, когда рация свёрнута.
Первую передачу сделайте в самой рации — так Android выдаст доступ к микрофону.

### Постоянное уведомление

Пока рация работает, в шторке висит уведомление: «на связи», «приём: ПОЗЫВНОЙ», «передача» или
«нет связи», канал, позывной и сервер. Кнопки: **Кнопка PTT поверх** и **Выключить**.

«Назад» и «свернуть» рацию не выключают — приём продолжается в фоне. Выключить: ✕ над рацией,
«Выключить» в уведомлении или смахнуть рацию из недавних приложений.

### Микрофон и наушники

Микрофон открыт только во время передачи и отпускается через 1,5 с после PTT: пока микрофон открыт,
Android держит телефон в режиме звонка и не переключает звук на наушники. С включённым **VOX**
микрофон нужен всё время — наушники тогда лучше подключать до запуска рации.

### Чего нет на телефоне

**14 HOST** (свой сервер), **15 TOP**, полоска поверх игр и горячие клавиши клавиатуры — только на ПК.

## Сеть: подключение не из дома

> **Мобильный интернет.** Сейчас у мобильных операторов соединение с сервером эфира
> (ПК-рацией друга) проходит **только через VPN с иностранным сервером**. Без VPN на мобильном
> интернете рация не подключается — Android пишет «нет связи… Software caused connection abort»
> или «сервер не отвечает». **На Wi-Fi всё работает без VPN.** Включите VPN на телефоне и
> переподключитесь (MENU → 12 SERVER → тот же адрес).

- **Одна Wi-Fi сеть** — вводите локальный адрес ПК (`ipconfig` → «IPv4-адрес»), например
  `192.168.1.10:8765`. Гостевые Wi-Fi сети часто не пускают устройства друг к другу.
- **Из интернета** — нужен внешний адрес. HOST просит роутер открыть порт по UPnP и показывает
  внешний адрес, если получилось. Если провайдер выдаёт «серый» IP (CGNAT), снаружи к ПК не
  подключиться — поможет туннель (например, `cloudflared tunnel --url http://localhost:8765`, адрес
  вида `xxx.trycloudflare.com` вводится без порта) или VPN-сеть (Tailscale, ZeroTier, Radmin VPN).
- Проверяйте внешний адрес с мобильного интернета: многие роутеры не пускают по внешнему адресу
  изнутри своей же сети.
- **Брандмауэр Windows** при первом включении HOST спрашивает доступ — разрешите для частных сетей.

Адрес без порта (`radio.example.ru`) рация открывает по защищённому соединению (wss), адрес с портом
или IP — по обычному (ws, порт по умолчанию 8765).

## Приватность и шифрование

- Сервер **без пароля**: подключиться, слушать открытые каналы и выйти в эфир может любой, кто знает
  адрес. Позывные не проверяются.
- **SCR** шифрует звук прямо на устройстве (AES-GCM, ключ выводится из фразы) — сервер пересылает
  байты, которые не может прочитать. Шифрованный канал слышен только с тем же ключом; с другим —
  цифровой треск. Ключ передавайте собеседникам сами; берите фразу из нескольких слов.
- Даже с SCR видно, **кто, когда и на какой частоте** говорит, — шифруется только звук.
- Сервер ничего не записывает на диск. Настройки и ключи хранятся на вашем устройстве.

## Если что-то не работает

| Что видно | Что делать |
|---|---|
| Нет **NET** на ПК | Проверьте адрес в **12 SERVER**, включён ли сервер, брандмауэр |
| На мобильном интернете нет связи, на Wi-Fi есть («Software caused connection abort») | Включите VPN с иностранным сервером — без него мобильные операторы не пускают к серверу |
| На телефоне внизу «порт закрыт или сервер выключен» | Сервер не запущен или адрес/порт неверный |
| «сервер не отвечает» / «нет маршрута» | Телефон не достаёт до сервера: другая сеть, серый IP, VPN |
| «адрес не найден» | Опечатка в домене |
| «сервер отказал (403)» | Сервер не пускает клиента — сообщите, какой это сервер |
| «МИКРОФОН ЗАПРЕЩЁН» | Разрешите микрофон рации в настройках Android |
| Кнопка PTT поверх не появилась | Разрешите «поверх других приложений» и сверните рацию |
| Android не ставит APK поверх старого | Старая версия подписана другим ключом — удалите её один раз |

## Устройство проекта

```
radio-walkie/            Рация для ПК (Electron) — исходный код рации
  web/                   Сама рация: страница, стили, звук, связь, шифрование
  main.js, preload.js    Оболочка Windows: окна, полоска, свой сервер, горячие клавиши
  air-server.js          Сервер эфира (ретрансляция, ничего не записывает)
  upnp.js, hotkeys.js    Проброс порта в роутере, клавиши из любого окна
radio-air/               Радиостанция для Android: музыка из папки в FM-эфир
android/                 Рация для Android
  app/src/main/java/…    MainActivity, AirSocket, WalkieService, PttBubble, AirState
  app/src/main/assets/android/   bridge.js, android.css — адаптер рации под телефон
  tools/sign_v2.py       Подпись APK (APK Signature Scheme v2) вне CI
.github/workflows/       Сборка APK, установщика Windows и релизов
```

**Как устроена Android-версия.** APK содержит `radio-walkie/web` без изменений — Gradle копирует
папку при каждой сборке. На ПК страницу рации открывает Electron и даёт ей `window.radioDesktop`
(`preload.js`); на Android то же делает `bridge.js`, поэтому рация работает как ПК-программа: то же
меню, та же логика подключения. Соединение с сервером открывает Java (`AirSocket`, OkHttp) с тем же
`Origin: app://radio`, что у ПК-рации, — для сервера телефон неотличим от ПК.

**Протокол.** WebSocket `/ws`. Текстовые сообщения — JSON (`tune`, `onair`, `offair`, `welcome`,
`station-on`, `station-off`, `listeners`, `codec`), двоичные — звук: 4 байта номера станции + пакет.
Звук: 16 кГц, моно, пакеты по 40 мс, сжатый — Opus (~18 кбит/с) или IMA ADPCM (~64 кбит/с).

**Кодек передачи выбирает сервер.** Приёмник в `tune` сообщает, что понимает (`codecs: ["opus"]`).
Сервер присылает станции `{"type": "codec", "codec": "opus"}`, только когда Opus понимают все, кто её
слышит, — иначе `"adpcm"`. Старые рации Opus не декодируют, поэтому, пока на канале есть хоть одна,
весь канал идёт в ADPCM. Старый сервер `codec` не шлёт — тогда всегда ADPCM. Сам звук сервер не разбирает.

**Автообновление.** Рация и радиостанция сами проверяют [релизы](https://github.com/BuninSil/Walkie-Walkie/releases)
(при каждом входе в приложение и раз в 6 часов в фоне), скачивают новую версию, проверяют, что это то же приложение с тем же
ключом подписи, и ставят её — рация не во время передачи, станция не во время эфира. Первый раз Android
попросит разрешить установку обновлений и подтвердить; дальше на Android 12+ обновления ставятся сами.
Вручную — «Обновления» в настройках рации (⚙) и на экране станции; там же «Обновлять автоматически».

Все APK начиная с 1.0.11 подписаны одним постоянным ключом (сертификат SHA-256
`E7:DD:C0:8B:94:FE:2D:00:DF:BF:49:26:2E:2F:DA:A5:D0:85:80:1B:D2:DA:8E:8F:42:09:C4:73:51:2C:73:B2`),
а номер версии растёт с каждой сборкой — поэтому новые версии ставятся поверх старых.

- Если в секретах репозитория есть `WALKIE_KEYSTORE_BASE64` и `WALKIE_KEYSTORE_PASSWORD`, CI сам
  выпускает подписанный APK (артефакт `walkie-android-apk`).
- Без секретов CI кладёт неподписанный APK в ветку `apk-unsigned`; его подписывают тем же ключом:
  `python android/tools/sign_v2.py unsigned.apk Walkie.apk walkie-release.p12 ПАРОЛЬ`.
- Релиз: подписанный APK и `notes.md` пушатся в ветку `apk-release` — workflow «Release» создаёт
  релиз `v1.0.N` с APK и удаляет ветку.

Ключ в репозиторий не кладётся. Без него обновить установленную рацию нельзя.
