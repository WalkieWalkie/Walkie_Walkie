# Рация

Рация на рабочий стол для эфира «Радио» — по мотивам Quansheng UV-K5. Каналы PMR446 и LPD,
любая частота 400–470 МГц, FM-радио, VOX, ROGER, двойное прослушивание, шифрование и компактная
полоска поверх игр с горячими клавишами.

Связь идёт через **сервер эфира**. Его можно открыть прямо из рации (пункт меню 14 HOST) или
подключиться к чужому — например, к серверу друга с программой «Радио» или `server.py`.
Все они говорят на одном протоколе.

## Установка

**Готовый установщик** `Walkie-Setup-0.1.0.exe` ставится в профиль пользователя без прав
администратора. Он не подписан, поэтому Windows может показать «Windows защитил ваш компьютер» —
нажмите «Подробнее» → «Выполнить в любом случае».

**Из исходников** (нужен [Node.js](https://nodejs.org) 20 или новее):

```bash
npm install
npm start
```

`npm start` запускает рацию, `npm run dist` собирает установщик в папку `dist`.

## Первое подключение

1. Включите рацию щелчком по ручке сверху.
2. **MENU → 12 SERVER → MENU**, наберите адрес сервера на клавиатуре (например `203.0.113.5:8765`
   или `radio.example.ru`), **Enter**, затем **MENU** — сохранить.
3. На экране появится **NET** — связь есть. Выберите тот же канал, что у собеседников, и говорите,
   удерживая **PTT** (или пробел, или **F8** из любого окна).

**Свой сервер:** **MENU → 14 HOST → ON**. Рация откроет сервер на порту 8765, попросит роутер
открыть порт (UPnP) и покажет адрес для друзей. Сервер работает, пока открыта рация. Если у вас
«серый» IP или роутер не умеет UPnP, друзья из интернета не подключатся — только из вашей сети.

Гости могут зайти и из браузера по адресу сервера: откроется та же рация. Но браузер пускает к
микрофону только по HTTPS или на `localhost`, поэтому с простого `http://адрес:8765` можно только
слушать.

## Частоты

- **MR** — каналы: PMR446 1–16 (446.00625–446.19375 МГц) или LPD 1–69 (433.075–434.775 МГц);
- **VFO** — любая частота 400–470 МГц (цифрами: `446006` → 446.00625 с учётом шага);
- **FM-радио** 88–108 МГц — **F+0**.

Каналов два — **A** и **B**, рабочий отмечен ▶.

## Кнопки

| Кнопка | Что делает |
|---|---|
| Ручка | Щелчок — включить/выключить, колесо или протяжка вверх-вниз — громкость |
| PTT (сбоку) | Держите и говорите. То же — пробел. **F8** — передача из любого окна |
| MON (сбоку) | Monitor: открыть шумоподавитель и послушать эфир |
| ☼ (сбоку) | Фонарик |
| ▲ ▼ | Канал или частота (в меню — пункт или значение) |
| 0–9 | Номер канала (MR) или частота (VFO, FM) |
| MENU / EXIT | Меню и подтверждение / назад, отмена, выход из FM |
| Держите ✱ | Сканирование: останавливается на передаче и ждёт 3 с после неё |
| F, затем цифра | **1** PMR↔LPD, **2** канал A/B, **3** VFO/MR, **7** VOX, **0** FM-радио |
| Держите F | Блокировка кнопок (PTT и боковые работают) |

Над рацией: булавка — поверх всех окон, ▭ — свернуть в полоску, черта — свернуть, ✕ — закрыть.
Рацию можно перетаскивать за корпус, место запоминается.

Светодиод: красный — передача, зелёный — приём. На экране: уровень сигнала, F, DW, VOX, S (шифр),
MON, замок, NET (связь с сервером).

## Меню

MENU, затем ▲▼ или номер пункта цифрами; MENU — изменить, MENU — сохранить, EXIT — отмена.
Текст (позывной, адрес, ключ) набирается на клавиатуре компьютера, Enter — готово, Esc — отмена.

| № | Пункт | Значения |
|---|---|---|
| 1 | SQL — шумоподавитель | 0–9 (0 — выключен) |
| 2 | STEP — шаг частоты в VFO | 2.5 / 5 / 6.25 / 10 / 12.5 / 25 кГц |
| 3 | SCR — скремблер: ключ и передачи, и приёма | OFF, сохранённые ключи, «новый» |
| 4 | VOX — передача голосом | OFF, 1–10 (чувствительность) |
| 5 | MIC — чувствительность микрофона | 0–4 |
| 6 | TOT — предел длины передачи | 1–10 мин |
| 7 | ROGER — сигнал в конце передачи | ON / OFF |
| 8 | DW — двойное прослушивание A+B | ON / OFF |
| 9 | BEEP — звук кнопок | ON / OFF |
| 10 | ABR — подсветка экрана | всегда, 5–30 с |
| 11 | NAME — позывной | текст с клавиатуры |
| 12 | SERVER — сервер | недавние адреса или новый |
| 13 | AUTO — подключаться при запуске | ON / OFF |
| 14 | HOST — свой сервер | ON / OFF (показывает адрес для друзей) |
| 15 | TOP — поверх всех окон | ON / OFF |

**Двойное прослушивание.** Слышны оба канала. Если ответили на втором, у него появляется «>», и
5 секунд после приёма PTT отвечает туда же.

**Шифрование (SCR)** — как скремблер настоящей рации: один ключ и на передачу, и на приём.
Звук шифруется прямо на компьютере (AES-GCM, ключ выводится из фразы), сервер пересылает байты,
которые не может прочитать. Шифрованный канал слышен, только если в SCR выбран тот же ключ; при OFF
или другом ключе — цифровой треск. Ключ передайте собеседникам сами, не через эфир. Берите фразу из
нескольких слов: короткий ключ вроде `4271` подбирается перебором.

## Полоска поверх игр

Кнопка ▭ над рацией сворачивает её в полоску (обратно — ⤢ на полоске). Это та же рация: связь
не рвётся, каналы и настройки те же.

```
● ГОСТЬ │ A▶ PMR 1 │ B 433.075 │ ▮▮▮▯▯ │ F8 │ ⚙ ⤢
```

- **Лампа:** серая — тихо, зелёная с позывным — кто-то говорит, красная с таймером — говорите вы,
  мигающая оранжевая — нет связи с сервером, синяя — сканирование.
- **Каналы A и B:** щелчок — сделать рабочим, колесо мыши — сменить канал.
- **Микрофон:** уровень голоса; отметка — порог VOX.
- Полоска не забирает фокус у игры и держится поверх всех окон. Её можно перетащить.

**⚙ Настройки полоски:** горячие клавиши (щёлкните по полю и нажмите клавишу или боковую кнопку
мыши), режим рации на клавише («держу — говорю» или «нажал / нажал»), прозрачность, громкость,
проверка микрофона и «мышь насквозь» (с зажатым **Alt** полоску можно двигать и нажимать).
По умолчанию: рация — **F8**, спрятать/показать — **Ctrl+Shift+F8**.

Горячие клавиши работают в любом окне, в том числе в играх: рация слушает клавиатуру и мышь через
модуль [uiohook-napi](https://github.com/SnosMe/uiohook-napi), как Discord для push-to-talk.
Нажатия только сравниваются с назначенными клавишами, никуда не записываются и не отправляются.
В играх полоска видна в режиме «Оконный без рамки»; в эксклюзивном полноэкранном её не видно, но
клавиши работают.

## Что стоит знать о приватности

- Сервер **без пароля**: подключиться, слушать открытые каналы и выйти в эфир может любой, кто знает
  адрес. Позывные не проверяются.
- Открытые каналы слышат сервер и все, кто настроится на частоту. Без HTTPS звук идёт по сети
  незашифрованным. Для приватного разговора включайте SCR.
- Даже с SCR видно, **кто, когда и на какой частоте** говорит, — шифруется только звук.
- Сервер ничего не записывает на диск. Настройки и ключи рации хранятся на вашем компьютере.

## Устройство

| Файл | Что это |
|---|---|
| `main.js` | Оболочка: окно рации, полоска, свой сервер, горячие клавиши |
| `preload.js` | Мост между страницей рации и оболочкой |
| `hotkeys.js` | Горячие клавиши из любого окна |
| `air-server.js` | Сервер эфира: ретранслирует живые станции, ничего не записывает |
| `upnp.js` | UPnP: открыть порт в роутере и узнать внешний IP |
| `web/widget.html`, `web/css/widget.css`, `web/js/widget.js` | Сама рация |
| `web/js/engine.js`, `stations.js`, `audio-kit.js` | Приёмник: шум, настройка, встроенные станции FM |
| `web/js/live.js`, `link.js`, `crypto.js` | Живой эфир, связь с сервером, шифрование |
| `web/js/codec.js` | Сжатие голоса IMA ADPCM: 16 бит → 4 бита на сэмпл |
| `web/js/worklets/capture.js` | Захват микрофона: 16 кГц, пакеты по 40 мс |

Звук в эфире: 16 кГц, моно, пакеты по 40 мс, сжатые в IMA ADPCM — около 64 кбит/с на станцию.
